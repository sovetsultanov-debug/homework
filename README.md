# Домашние задания

Курс программирования, JavaScript. Запуск любого файла: `node homework1.js`.

| Файл | Тема |
|------|------|
| homework1.js | Функции: сложение, вычитание, умножение, деление (с проверкой деления на ноль) |
| homework2.js | Переменные и `if / else`: средний балл и бонусы за домашку и посещаемость |
| homework3.js | Массив объектов и `for...of`: буквы в названиях городов, самое длинное название |
| homework4.js | То же на английском: имена команды, сумма и средняя длина, самое длинное имя |
| homework5.js | Оценки A–F, средний процент, лучший и худший результат |

## Props: ключевые понятия
- Props (сокращение от «properties») — аргументы, которые передают компоненту. Благодаря им компонент становится динамическим и переиспользуемым.
- Через props данные идут от родительского компонента к дочернему.
- Пример: компонент `Welcome` получает prop `name` от `App` и использует его внутри JSX.

```jsx
function Welcome(props) {
  return <h1>Hello, {props.name}!</h1>;
}

function App() {
  return <Welcome name="John" />;
}
```
